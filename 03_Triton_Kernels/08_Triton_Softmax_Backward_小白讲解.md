## 一句话总结

这个 notebook 教你用 Triton 写 Softmax 的反向传播：每列梯度不是简单相乘，而是要先算一个整行共享的点积修正项，再逐列修正。

## 为什么需要它：痛点是什么

前向 Softmax 把一行分数变成和为 1 的概率。反向传播时，一个天真的想法是"输出对输入，梯度一一对应相乘就行了"：`grad_x = y * g`。但 Softmax 的每一列概率都共用同一个分母——改一个输入分数，整行概率都会跟着变。这就像班级按分数占比分奖学金：一个人考高了，其他所有人的占比都自动下降，不能只看自己的卷子。

朴素 PyTorch 靠自动微分帮你做对了这件事，但如果你要手写融合的反向 kernel（比如给注意力算子提速），就必须自己推出正确公式，而且不能真去建 $N\times N$ 的雅可比矩阵（Jacobian，记录每个输出对每个输入导数的矩阵）——行宽 4096 时那是 1600 万个数。

## 核心问题

- 为什么 `grad_x = y * g` 是错的？漏掉的整行修正是什么？
- 怎样不存雅可比矩阵，只用一个行内点积就得到正确梯度？
- 有没有简单的数学性质可以自检反向结果？

## 解决思路：一步步看懂

1. **从链式法则展开。** 记上游梯度 $g_i=\partial L/\partial y_i$，Softmax 导数为 $\partial y_j/\partial x_i=y_j(\mathbf{1}_{i=j}-y_i)$，求和整理后得到紧凑公式：

   $$\frac{\partial L}{\partial x_i}=y_i\Big(g_i-\underbrace{\sum_j y_j g_j}_{d}\Big)$$

   文字说：每列梯度 = 本列概率 ×（本列上游梯度 − 整行共享修正项 $d$）。$d$ 是本行概率与梯度的加权点积。

2. **先归约、再广播。** 一个 Program 负责一行：先读入概率 $y$ 和上游梯度 $g$，归约出标量 $d$；再把 $d$ 广播（broadcast，一个数发给所有列）用于每列。参考实现核心就两行：

   ```python
   row_dot = tl.sum(y * grad_y, axis=0)   # 整行共享的修正项 d
   grad_x = y * (grad_y - row_dot)        # 每列用自己的 y 和 g，减同一个 d
   ```

3. **手算一个小例子。** $y=(1/4,\ 3/4)$、$g=(2,\ -1)$：逐列乘得 $(1/2,\ -3/4)$，求和 $d=-1/4$；梯度为 $(1/4)(2+1/4)=9/16$ 和 $(3/4)(-1+1/4)=-9/16$。两列共用同一个 $d$，但各自的概率、梯度不同。

4. **补齐列填零。** 行宽补到 2 的幂后，无效列的 $y$ 和 $g$ 都置 0（`other=0.0`），乘积为 0，不污染点积；写回时只存有效列。行宽不是 2 的幂、输入是非连续视图时，用真实行步长 `row_stride` 寻址。

5. **两条自检性质。** 其一：整行输入同加一个常数，概率不变，所以沿这个方向损失不变，每行梯度之和应为 0（上例 $9/16$ 与 $-9/16$ 正好抵消）。其二：若整行上游梯度都是常数 $c$，则 $d=c$，所有梯度为 0。只写 `y * g` 的实现过不了这两关。注意行梯度和为零只是必要条件，不能替代与参考对照。

## 关键概念速查表

| 术语 | 大白话解释 |
|---|---|
| 上游梯度 | 损失传回来的 $\partial L/\partial y_i$，记作 $g$ |
| 雅可比矩阵 | 所有输出对所有输入的导数表；正确做法是不显式建它 |
| 行点积（row_dot） | $d=\sum_j y_j g_j$，整行共享的修正项 |
| 广播（broadcast） | 把归约出的一个标量发给本行所有列使用 |
| 掩码补零 | 无效列的 y、g 都填 0，让它们对点积无贡献 |
| 平移不变性 | 整行加同一常数概率不变，对应行梯度和为零 |
| `tl.sum(..., axis=0)` | 沿块内方向归约成标量 |

## 小白常见疑问

- **Q：为什么不能只算 `y * g`？** 那漏掉了分母带来的耦合：所有概率共用分母，一处输入变化牵动整行。漏掉 $d$ 后行梯度和不为零，常量梯度用例也过不了。
- **Q：公式里有双重求和，不会很慢吗？** 不会。整理成一个行内点积 $d$ 后，整行只需一次归约加一次逐列修正，两遍扫完。
- **Q：输入是非连续张量怎么办？** 骨架按真实步长 `row_stride` 定位每行起点，或先整理成连续布局；两种方式都不改变概率与梯度按行对应的关系。
- **Q：梯度和为零能当全部验证吗？** 不能，它只是必要条件；必须再与 PyTorch 自动微分逐元素对照。

## 动手验证：怎么知道自己做对了

`_check_backward_case` 先把 logits 设 `requires_grad`，用 `torch.softmax` + 自动微分算出参考梯度，再与 Triton 输出逐元素对照。用例覆盖非 2 次幂行宽（如 3×17）、非连续布局、常量/零上游梯度、接近单点集中的概率；另断言常量梯度输出为零、普通输入的行梯度和接近零。`test_backward_input_contract` 还检查非法输入（形状不符、错设备、行宽超 4096 等）会被拒绝。
