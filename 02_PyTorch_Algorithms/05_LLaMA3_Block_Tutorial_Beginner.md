## 一句话说清

解码器块是大模型里重复堆叠的一层：注意力先让词元之间交换信息，前馈网络再在每个词元内部加工，两步的结果都加回原来的向量。这本 notebook 练的是按顺序把它们组装起来。

## 为什么需要它

前面的几节分别造好了零件：RMSNorm 管尺度，SwiGLU 管非线性，RoPE 管位置，GQA 管上下文。解码器块要把它们装进同一层，装的时候有三处容易出错。

- **顺序错了**。输入是 `1`，注意力加 `2`，MLP 加 `3`。正确的顺序是 MLP 读到 `3`，输出 `6`。如果 MLP 读的还是最初的 `1`，它就看不到这一层刚从上下文取来的信息。
- **层和层没串起来**。3 个块各加 `4`，输入是 `1`，串起来是 `13`。每一层都从最初的输入算起再覆盖，最后只剩 `5`。
- **换零件时弄坏了接口**。换注意力、换 MLP、换归一化之后，块的输入输出形状和残差接口要原样保留，否则接不上。

这本 notebook 只练“组装”：写对一个块里的两次相加，再把多个块串成一条链。

## 先认识几个词

| 词 | 人话解释 |
|:---|:---|
| 解码器块（Decoder Block） | 大模型里重复堆叠的一层。本节的一层是：归一化、注意力、相加，再归一化、MLP、相加 |
| 主状态 / 残差流 | 主状态是每个词元当前的隐藏向量，形状 `[B, S, C]`。它一层层往下传、每层往上加一点，这条路径叫残差流 |
| 子层 / 增量（delta） | 注意力和 MLP 这两个变换分支叫子层。注意力的增量叫上下文更新量，MLP 的增量叫通道更新量，形状都和主状态一样 |
| 前置归一化（Pre-Norm） | 先归一化，再把结果送进子层。归一化只管子层的输入，主状态本身不被改写 |
| 残差更新 | 把子层的增量加回主状态：`h + 增量` |
| 替身（stub） | 接口和真组件一样、计算被简化的小模块。本题的归一化替身只做逐通道缩放，注意力替身只做线性映射 |
| 梯度连通性 | 反向传播之后，每个参数都能拿到梯度（`param.grad` 不是 `None`） |

## 核心思路

一个块的输入是主状态 `h`，形状 `[B, S, C]`。块做两轮“归一化 → 子层变换 → 相加”，输出的形状不变：

```text
h'     = h  + Attention( Norm_1(h) )     # 第一轮：注意力在词元之间交换信息
h_next = h' + MLP( Norm_2(h') )          # 第二轮：MLP 在每个词元内部重组通道
```

符号说明：`B` 是批量大小，`S` 是词元数，`C` 是隐藏宽度；`h'` 是第一次残差更新后的状态，也是第二轮归一化的输入；`h_next` 是块输出，可以直接作为下一块的输入。两个加号就是两次残差更新：子层只产生增量，主状态自己一直往下传。

多个块堆叠时，第 `l + 1` 层的输入必须是第 `l` 层的完整输出。

本题的块用的是替身：`norm_1`、`norm_2` 只做逐通道缩放，`attention_update` 只做线性映射。它们不是 RMSNorm 或真实注意力，只保证输出和输入同形状。MLP 保留了真实的 SwiGLU 计算。

下面把“加回去”的几种情况用小数走一遍：

```python
h = 1.0                                  # 输入的主状态
attention_delta, mlp_delta = 2.0, 3.0    # 两个子层产生的增量

h1 = h + attention_delta                 # 第一次残差更新
print(h1)                                # MLP 读到的是它
h_next = h1 + mlp_delta                  # 第二次残差更新
print(h_next)

# 堆叠 3 个块，每个块加 4
h = 1.0
for _ in range(3):
    h = h + 4.0                          # 下一层读取上一层的输出
print(h)

# 错误写法：每一层都读最初的输入，再覆盖
h = 1.0
for _ in range(3):
    h = 1.0 + 4.0
print(h)

# 增量要加回原来的主状态，不是加回归一化后的结果
x, normed = 1.0, 0.5                     # 归一化把输入缩成了 0.5
print(normed + 2.0, x + 2.0)
```

```text
3.0
6.0
13.0
5.0
2.5 3.0
```

前三行是正确的写法：MLP 读到 `3.0`，块输出 `6.0`，3 个块串起来是 `13.0`。第 4 行是错误写法的结果，只有 `5.0`。最后一行：增量加回归一化后的结果是 `2.5`，加回原来的主状态才是 `3.0`。

## 容易踩的坑

- **MLP 读的是原始输入**：第二次前置归一化必须读已经加上注意力更新的状态 `h'`。读最初的 `h`，MLP 就看不到这一层刚取来的上下文。
- **增量加错了地方**：子层读的是归一化后的输入，但增量要加回原来的主状态，不是加回归一化后的结果。
- **两次更新合成一次**：注意力和 MLP 解决的问题不同，不能把两条更新合并成一次无序求和。
- **各层并行覆盖**：后一层必须读取前一层的完整输出。每层都从最初的输入算起再覆盖，固定增量就不会按层累积。
- **以为形状对就够了**：局部组件能产生同形状输出，只说明接口可连接。深度增加还会放大初始化、残差尺度、归一化位置和梯度传播之间的相互作用。
