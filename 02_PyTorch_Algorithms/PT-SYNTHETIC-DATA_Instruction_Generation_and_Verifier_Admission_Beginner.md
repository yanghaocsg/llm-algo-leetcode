## 一句话说清

让模型自己写出训练数据之后，这本 notebook 教你给每条新生成的样本做筛查：记清它是怎么产生的，和已有题目像不像，回答有没有通过验证，最后分成接纳、复核、拒绝三类。

## 为什么需要它

真实示范不够用时，可以让模型生成新的“指令加回答”。但数量多不等于有用。有三种常见的坏情况：

- 模板复写。只换了少数字词，任务要求没变，比如反复改写同一种退款提问。结果是大量近重复，挤占数据预算。
- 评测题重现。生成出来的题目正好和评测集里的一样。训练过它，评测成绩就说明不了模型对没见过的任务表现如何。
- 没验证的流畅回答。读起来通顺，内容却是错的，照样被送进训练集。

这本 notebook 把筛查拆成四件事：记清每条样本怎么产生的，算它和已有题目有多像，看回答有没有通过验证，最后给出接纳、复核或拒绝，只把接纳的交给下一本 notebook 继续审计。

## 先认识几个词

| 词 | 人话解释 |
|:---|:---|
| 任务蓝图（task blueprint） | 生成前写明的能力目标、输入范围和成功条件，用来说明要补足哪类示范 |
| 模板复写 | 只替换少数字词、没有增加新任务要求的生成，等于换了说法的同一道题 |
| 生成身份（generation identity） | 一个四元组：任务蓝图版本、生成器版本、提示模板版本、候选标识 |
| 字符 n-gram | 连续 n 个字符组成的片段，比如“三步退款”在 n 为 2 时是“三步”“步退”“退款” |
| 验证器（verifier） | 检查候选的规则或程序：格式规则查结构，执行验证查运行结果，质量评分给开放式回答打分 |
| 冻结评测集 | 预先固定成员和用途的验证或测试集合，里面的题目不能进入训练 |

## 核心思路

每条候选带着任务蓝图、生成来源、参考指令和验证结果进来。筛查分四步，对应四个 TODO。

第一步，记清来源（TODO 1）。Step 1 的公式是 `g(z) = (b(z), m(z), p(z), s(z))`：`z` 是一条候选，`b(z)`、`m(z)`、`p(z)` 分别是任务蓝图、生成器、提示模板的版本，`s(z)` 是候选在批次内的标识。四项缺一不可，缺了就报错，否则之后分不清错误出在任务设计还是生成配置。这个身份只回答“样本怎样产生”，不判断内容好坏。

第二步，看像不像（TODO 2）。把指令切成所有连续两个字的片段，比较候选和参考指令的片段集合。Step 2 的公式写成纯文本是：

```text
S(z, D)       = max over d in D of |N(q_z) ∩ N(d)| / |N(q_z) ∪ N(d)|
novelty(z)    = 1 - S(z, D)
```

`N(q_z)` 是候选指令的片段集合，`N(d)` 是一条参考指令的片段集合，`D` 是参考指令的集合。分子是共有的片段数，分母是合起来一共有多少种片段，这个比值叫 Jaccard 相似度。`D` 为空时约定结果为 0。候选要和两组参考各比一次：已有的训练指令，以及同一批里的其他候选。

用 notebook 测试里的指令试一下：

```python
def bigrams(text):
    text = ' '.join(text.casefold().split())
    return {text[i:i + 2] for i in range(len(text) - 1)}

def jaccard(a, b):
    union = a | b
    return len(a & b) / len(union) if union else 1.0

new = bigrams('说明未发货订单如何修改收货地址')
old = bigrams('说明已发货订单如何修改收货地址')       # 只换了一个字
print(len(new), len(new & old), len(new | old))
print(jaccard(new, old))
print(jaccard(new, bigrams('计算两个矩阵的乘积')))    # 完全不同的任务
print(jaccard(new, new), max([], default=0.0))        # 精确重复；没有参考指令
```

```text
14 12 16
0.75
0.0
1.0 0.0
```

只换一个字的变体，相似度是 0.75，到了默认的复核线 0.72，要进入复核。完全不同的任务相似度是 0.0。相似度只是一项筛查信号，不代表语义等价。题目和冻结评测任务完全重合是单独查的，查到就直接拒绝。

第三步，验证并分类（TODO 3）。先看硬条件：指令和回答不为空，必需验证器都通过并留有版本和失败原因。任何一条不满足就是拒绝。都满足时再看质量分数 `Q`，notebook 举的例子是复核线 0.60、接纳线 0.80：

```text
Q < 0.60                  → 拒绝
0.60 <= Q < 0.80          → 复核
Q >= 0.80，且没有其他风险 → 接纳
```

拒绝优先于复核：同时命中污染和近重复时，原因都保留，决定仍是拒绝。

第四步，交接（TODO 4）。只有决定是接纳、并且原因清单为空的候选，才被复制成训练记录交给下一节。

## 容易踩的坑

- **把空字段补成一段文本**：来源字段为空要当作缺失并报错，不能转成看似有效的字符串。任一版本变化都必须改变身份。
- **把训练相似度和评测重合合成一个结论**：近重复可以进入人工复核，评测污染必须直接拒绝。两项要分开查。
- **高相似就直接拒绝**：相似度只是一项筛查信号，不代表语义等价。高相似候选进入的是复核。
- **高质量分数抵消了污染或验证失败**：拒绝优先于复核和接纳。同时命中时保留全部原因，决定仍是拒绝。
- **复核的候选跟着接纳的一起交接**：复核不等于已经修复。只有决定是接纳且原因清单为空的记录才交给下一节。
