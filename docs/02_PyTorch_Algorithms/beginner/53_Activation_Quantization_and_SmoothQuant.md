## 一句话说清

SmoothQuant 在量化前把激活里特别大的通道调小，把对应的权重调大，这一层的输出保持不变。这本 notebook 带你实现这个变换，并挑选调整的力度。

## 为什么需要它

只把权重压到 8 位，误差很小。再把激活也压到 8 位，输出误差却可能明显变大。原因是两边的分布不一样：权重通常比较平稳，激活却常常在少数几个通道上出现比其他通道大得多的值。

看一个小场景：激活有 4 个通道，其中一个通道的数值到了 120，其余都在 2 以内。量化时整张激活表共用一个缩放因子，它必须覆盖 120。于是 1、2 这样的普通值只能落到相隔很远的几个格子上，恢复时误差变大。权重那边没有这种异常值，却帮不上忙。

SmoothQuant 的办法是对每个输入通道做一次调整：激活除以一个数，权重乘以同一个数。两步相乘正好抵消，线性层的浮点输出不变。但激活的范围变小了，权重的范围变大了，量化的难度从激活一侧搬到权重一侧。这本 notebook 要判断的是：搬迁之后，输出误差是否真的降低。

## 先认识几个词

| 词 | 人话解释 |
|:---|:---|
| 激活（activation） | 模型处理当前输入时产生的中间值，也就是进入这一层的输入 `X` |
| W8A8 | 权重和激活都用 8 位表示的量化方式 |
| 异常通道（outlier channel） | 数值范围比其他通道大得多的那几个通道 |
| 逐张量量化 | 整个张量共用一个缩放因子。本题的激活和权重都是这样量化的 |
| 等价变换 | 改了数值的写法，但没改变计算结果。这里是 `X * W^T` 和 `(X / s) * (W * s)^T` 相等 |
| `alpha` | 0 到 1 之间的平滑强度。越大，通常激活一侧的范围缩得越多，权重一侧承接得越多 |

## 核心思路

输入是校准激活 `X`、浮点权重 `W` 和一组候选 `alpha`。量化和反量化由骨架提供，你要补三步：

1. 算平滑因子：对每个输入通道，取激活的绝对最大值和权重的绝对最大值，按公式算出一个数。
2. 做等价变换：激活逐通道除以它，权重在输入通道维乘以它。
3. 选 `alpha`：每个候选都把两侧量化再恢复、相乘，和原始浮点输出比较，选输出误差最低的。

notebook 的公式，这里是纯文本版：

```text
Y = X * W^T = (X / s) * (W * s)^T        激活除以 s，权重乘以 s，输出不变
s_j = a_j^alpha / w_j^(1 - alpha)        a_j：通道 j 的激活绝对最大值；w_j：通道 j 的权重绝对最大值；0 <= alpha <= 1
平滑后的通道范围（忽略正下限）：  激活 (a_j * w_j)^(1 - alpha)     权重 (a_j * w_j)^alpha
```

符号说明：`j` 是输入通道的编号，`X` 的最后一维和 `W` 的输入维对齐的是同一组通道；`s_j` 是通道 `j` 的平滑因子，必须为正；`alpha` 是平滑强度。从最后一行可以看出：`alpha` 接近 0 时权重的范围趋近 1，接近 1 时激活的范围趋近 1。

下面用题目测试里的样本走一遍。激活是 3 个样本、4 个输入通道，第二个通道是异常通道：

```python
import torch

X = torch.tensor([[1.0, 120.0, 0.5, -1.0], [2.0, -90.0, -0.5, 0.5], [-1.0, 80.0, 1.5, 2.0]])
W = torch.tensor([[1.0, 0.25, -2.0, 0.5], [-0.5, 0.50, 1.0, -1.5]])
ref = X @ W.T
act_max = X.abs().amax(dim=0)                  # 每个输入通道的激活绝对最大值
w_max = W.abs().amax(dim=0)                    # 每个输入通道的权重绝对最大值

def factor(alpha):                             # 逐通道平滑因子 s
    return act_max ** alpha / w_max ** (1 - alpha)

def q_dq(t):                                   # 对称逐张量 INT8：量化再恢复
    scale = t.abs().max() / 127
    return torch.clamp(torch.round(t / scale), -127, 127) * scale

def run(alpha):
    s = factor(alpha)
    sx, sw = X / s, W * s                      # 激活除以 s，权重乘以 s
    same = torch.allclose(ref, sx @ sw.T)      # 浮点输出是否等价
    out_mse = ((ref - q_dq(sx) @ q_dq(sw).T) ** 2).mean().item()   # 两侧量化后的输出误差
    print(same, round(float(sx.abs().max()), 4), round(float(sw.abs().max()), 4), round(out_mse, 4))

print(act_max, w_max, factor(0.5))
print("不平滑", round(((ref - q_dq(X) @ q_dq(W).T) ** 2).mean().item(), 4))
for alpha in (0.0, 0.5, 0.8, 1.0):
    run(alpha)
```


读三处：

- 第一行：四个通道的激活绝对最大值是 2、120、1.5、2，异常通道分到的平滑因子 15.4919 也是最大的。`alpha` 取 0.5 时，平滑因子就是“激活范围除以权重范围”再开平方。
- 第二行：不做平滑，两侧直接量化再相乘，输出误差是 0.8444。
- 后四行依次是 `alpha` 取 0、0.5、0.8、1，每行是浮点是否等价、激活峰值、权重峰值、输出误差。范围从激活一侧搬到了权重一侧，输出误差先降后升。注意 `alpha` 取 0 并不是不平滑，而是让权重的范围趋近 1。

浮点输出等价，只说明变换没有改变线性函数，不保证量化后的输出误差更小。

## 容易踩的坑

- **缩放方向弄反了**：激活要除以平滑因子，权重要乘以同一个因子，而且要乘在输入通道那一维。反过来做，浮点输出就不再等价。
- **范围是 0 的通道直接做除法**：要用正下限保护，平滑因子必须有限且为正。
- **在独立样本上重新算平滑因子**：`alpha` 和逐通道因子在校准样本上定下来之后要固定，独立评测只复用，不重新统计范围。
- **以为 `alpha` 越大越好**：改变强度不保证所有通道的绝对范围都同向变化，更不保证输出误差单调下降。要在候选集合里比输出误差。
- **把浮点等价当成量化误差更小**：两侧误差进入乘法后共同传播，不能要求两侧误差都下降，最终要看线性层输出误差。
