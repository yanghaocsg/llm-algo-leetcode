## 一句话说清

RMSNorm 把每个词元内部的一串数字调回到统一的大小，让深层网络的计算保持稳定。它比 LayerNorm 少一步“减均值”，所以计算更少。

## 为什么需要它

神经网络有很多层，数据要一层一层往下传。每一层都在做乘法和相加，数值可能越滚越大，也可能越缩越小。

看一个例子：向量 `[3, 4]` 连续经过 10 层，如果每层都把它放大 2 倍，到最后一层就是 `[3072, 4096]`。数值这么大，后面的计算容易溢出或者丢精度，模型也很难训练好。

归一化（normalization）就是在每层入口先把数据的大小拉回正常范围。以前常用 LayerNorm，它做两件事：先减均值，再按标准差缩放。RMSNorm 只保留缩放这一步，不减均值。notebook 里特意说明了这个取舍：RMSNorm 不是 LayerNorm 的近似，而是主动去掉“重新居中”这个要求。它合不合适，要由模型结构、初始化和训练结果一起决定。

## 先认识几个词

| 词 | 人话解释 |
|:---|:---|
| 词元（token） | 模型处理文本的最小单位，可以理解为一个字或一个词的一部分 |
| 隐藏向量（hidden state） | 每个词元在模型内部对应的一串数字，比如长度为 2 的 `[3, 4]` |
| 通道 | 隐藏向量里的一个位置。RMSNorm 在同一个词元的所有通道上做统计 |
| 均方根（root mean square，RMS） | 先平方、求平均、再开根号，可以理解为“这个向量的典型大小” |
| `eps` | 一个很小的正数（这里是 `1e-6`），加在根号里，防止除以 0 |
| `dtype` | 数据类型，比如 `float32` 精度高，`float16` 省显存但精度低 |

## 核心思路

对每个词元的向量 `x`，RMSNorm 做三步：

```text
rms = sqrt(mean(x_i^2) + eps)   # 1. 算出这个向量的典型大小
y   = x / rms                   # 2. 除以它，把向量缩放到固定大小
y   = y * gamma                 # 3. 乘上可学习的缩放参数 gamma，每个通道一个
```

符号说明：`x_i` 是向量里的第 `i` 个数，`mean` 是求平均，`gamma` 是训练时学出来的参数（代码里叫 `self.weight`），一开始全是 1。

下面用长度为 2 的向量试一下：

```python
import torch

x = torch.tensor([3.0, 4.0])
rms = torch.sqrt(x.pow(2).mean())   # eps 很小，这里先忽略
print(rms)
print(x / rms)

big = x * 10
print(big / torch.sqrt(big.pow(2).mean()))
```

```text
tensor(3.5355)
tensor([0.8485, 1.1314])
tensor([0.8485, 1.1314])
```

把向量整体放大 10 倍，除以均方根之后结果完全一样。归一化只关心各通道之间的比例，不关心整体大小。

## 容易踩的坑

- **沿错了维度**：统计只在最后一维做，也就是同一个词元的通道之间。跨批次或跨序列求平均，形状对不上，结果也不对。
- **写成了 LayerNorm**：减了均值就不是 RMSNorm 了。
- **缩放参数用了单个数字**：参数形状必须是 `[D]`，每个通道一个，否则会丢掉逐通道的缩放能力。
- **忘记恢复 `dtype`**：输入是 `float16`，输出也必须是 `float16`。
- **用低精度做统计**：平方之后数值容易溢出或丢精度，所以要先 `.float()` 再算。
