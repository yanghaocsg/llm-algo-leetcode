## 一句话说清

微调大模型时不必更新全部参数。LoRA 把原来的权重冻结住，只在旁边加两个小矩阵来学改动；训练完还能把改动并回原权重。

## 为什么需要它

微调最直接的做法是更新模型的全部参数。但这样除了模型权重，还要为每个参数保存梯度和优化器状态，显存压力迅速放大。而很多场景要的只是在已有能力上做小幅适配。

LoRA 的思路是：原来的权重一个都不动，在选定的线性层旁边并联一条很小的可训练支路。训练只更新这条支路，需要保存梯度和优化器状态的参数也就少了很多。部署前还能把支路的改动算出来，加回原权重，推理时不多出计算。

这本 notebook 带你实现一个最小的 LoRA 线性层，并检查三件事：开始训练时它不改变原层的输出，第一步梯度先到哪个矩阵，合并前后输出一致。

## 先认识几个词

| 词 | 人话解释 |
|:---|:---|
| 微调（fine-tuning） | 在已经训练好的模型上，用新数据继续训练，让它适应新任务 |
| 参数高效微调（PEFT） | 只训练一部分参数，或只新增少量参数来适配模型 |
| 低秩适配（LoRA） | PEFT 的一种：冻结原始权重，在旁边加一条可训练的低秩支路 |
| 基座 | 被冻结的原线性层，它的权重记为 `W_0` |
| 适配器（adapter） | 新增的可训练低秩分支；它挂在哪个线性层上，哪个层就是挂载位置 |
| 秩（rank） | 矩阵里独立方向的数量，记为 `r`，用来控制旁路的容量和参数量 |
| 随机失活（Dropout） | 训练时随机屏蔽部分输入以减轻过拟合，评估和合并核对时关闭 |

## 核心思路

一个线性层做的事是 `h = W_0 @ x`：输入 `x` 有 `d_in` 个数，权重 `W_0` 的形状是 `d_out × d_in`，输出 `h` 有 `d_out` 个数。LoRA 在旁边加两个小矩阵：`A` 的形状是 `r × d_in`，把输入压到 `r` 个数；`B` 的形状是 `d_out × r`，再变回 `d_out` 个数。Step 2 的公式写成纯文本是：

```text
h = W_0 @ x + (alpha / r) * B @ A @ x
新增的可训练参数量 = r * d_in + d_out * r = r * (d_in + d_out)
```

`alpha` 是控制增量幅度的缩放超参数，`alpha / r` 是缩放系数。训练开始时 `B` 全为 0，所以增量是 0，输出和原层完全一样。之后第一个反向传播步骤里 `B` 先拿到梯度；`A` 的梯度要乘上 `B`，所以暂时是 0，等 `B` 离开零点后才开始更新。这是零初始化带来的预期顺序，不是梯度链路断了。

用很小的维度走一遍：

```python
import torch

torch.manual_seed(0)
d_in, d_out, r, alpha = 4, 3, 2, 4
scaling = alpha / r                                   # 4 / 2 = 2
W0 = torch.randn(d_out, d_in)                         # 冻结的基座权重
A = torch.randn(r, d_in, requires_grad=True)          # [r, d_in]
B = torch.zeros(d_out, r, requires_grad=True)         # [d_out, r]，一开始全是 0
x = torch.randn(d_in)

h = W0 @ x + scaling * (B @ A @ x)
h.sum().backward()
print(torch.allclose(h, W0 @ x), bool(torch.any(B.grad != 0)), bool(torch.any(A.grad != 0)))

with torch.no_grad():
    B.normal_()                                       # 训练一段时间后，B 离开零点
delta = (B @ A) * scaling
print(torch.allclose(W0 @ x + delta @ x, (W0 + delta) @ x))
print(8 * (128 + 256), 128 * 256)                     # notebook 测试那一层：新增参数，基座参数
```

```text
True True False
True
3072 32768
```

第一行的三个结果：一开始输出等于基座输出，`B` 的梯度非零，`A` 的梯度全零。第二行说明写回基座的增量和旁路算出来的结果等价，所以部署时可以直接用 `W_0 + delta`，省掉旁路的两次矩阵乘法。第三行是 notebook 测试里那一层的参数量：新增 3072 个可训练参数，基座权重有 32768 个。

旁路还可以加随机失活，它只作用在旁路的输入上。因为训练模式下每次输出都不同，比较合并前后的输出要在评估模式下做。同一份增量只能写回一次。

## 容易踩的坑

- **忘了冻结基座**：要把 `self.linear.weight.requires_grad` 设成 `False`，否则基座权重也会被更新，可训练参数量就不对了。
- **A 和 B 的形状写反**：`lora_A` 是 `[r, in_features]`，先降维；`lora_B` 是 `[out_features, r]`，再升维。
- **看到 A 的首步梯度为零以为出了错**：`B` 初始为 0 时 `A` 的梯度本来就是 0，这是预期顺序。`B` 离开零点后 `A` 才开始更新。
- **两条分支用了不同的输入，或漏了缩放**：主分支和旁路要用同一个 `x`，旁路输出要乘 `alpha / r`。
- **重复合并**：同一份增量只能写回一次，第二次调用 `merge_weights` 不能再改主权重。
