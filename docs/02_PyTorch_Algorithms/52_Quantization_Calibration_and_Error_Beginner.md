## 一句话说清

量化前要先定一个范围：范围太大，普通值被挤得很粗糙；范围太小，超出的值会被截断。这本 notebook 教你用数据挑出一个两头都照顾到的范围。

## 为什么需要它

量化要把一批小数放进固定的整数格子里，格子之间的间距由范围决定。范围是 2 时，间距约 0.0157；范围是 100 时，间距约 0.7874。表示方式没有变，格子却粗了很多。

现在有一批权重，大部分落在 -2 到 2 之间，偏偏有一个特别大的数 100（异常值，outlier）。定范围时有三种做法会出问题：

- 按最大的算，范围取 100。间距变成约 0.7874，普通值只能落到相隔很远的几个格子上，恢复时误差大。
- 把范围定成 2。普通值几乎能精确恢复，但 100 被截到 2，这一个数就差了 98。
- 在定范围用的那批数据上量误差。这等于自己给自己打分，换一批数据结论可能就不成立。

所以需要一个可验证的选法：用一批样本定出几个候选范围，再用另一批没参与的数据量每个候选的误差和被截断的比例，先淘汰截断太多的，再选误差最低的。这本 notebook 实现的就是这个搜索。

## 先认识几个词

| 词 | 人话解释 |
|:---|:---|
| 校准集（calibration set） | 用来估计量化范围的那批样本数值，下面叫“校准数值” |
| 验证集（validation set） | 没有参与范围估计的另一批数值，只用来量误差和饱和率 |
| 分位数（quantile） | 把数据从小到大排好，80% 分位数就是有 80% 的数不超过它的那个值 |
| 裁剪（clipping） | 把范围定得比最大值小，超出的值按边界处理 |
| 饱和率（saturation rate） | 被裁剪的数占全部数的比例 |
| 均方误差（mean squared error，MSE） | 恢复值和原值之差的平方再取平均，越小说明恢复得越准 |
| 量化网格 | 范围和位宽定下后能表示的一串等距的值，间距就是缩放因子 |

## 核心思路

输入是校准数值、验证数值、几个候选分位数和一个饱和率上限。notebook 固定对称 INT8 和逐张量粒度（整个张量共用一个缩放因子），只搜索裁剪分位数。行里标着“校准”或“验证”的括号，说明这一步用哪批数据：

```text
range = quantile(abs(校准数值), q)       （校准）  range 是量化范围，q = 1.0 就是绝对最大值
scale = range / 127                      （校准）  缩放因子，也就是网格间距
raw   = round(x / scale)                 （验证）  还没截断的整数码
x_hat = clamp(raw, -127, 127) * scale    （验证）  恢复值，clamp 把超出范围的码截到边界
mse   = mean((x - x_hat)^2)              （验证）  均方误差
sat   = mean(abs(raw) > 127)             （验证）  饱和率
```

过程分四步。第一步生成候选：对每个分位数，只用校准数值算出范围和缩放因子。第二步验证候选：用这个缩放因子量化再恢复验证数值，算出均方误差和饱和率。第三步应用约束：淘汰饱和率超过上限的候选，一个都不剩就报错。第四步选择范围：在剩下的候选里选验证均方误差最低的，平局时取分位数更高的。

下面用 6 个校准数值和 6 个验证数值走一遍，候选分位数是 1.0 和 0.8：

```python
import torch
torch.set_printoptions(precision=4)

cal = torch.tensor([-100.0, -2.0, -1.0, 0.0, 1.0, 2.0])   # 校准数值，带一个异常值
val = torch.tensor([-2.0, -1.0, 0.0, 1.0, 2.0, 100.0])    # 验证数值

for q in (1.0, 0.8):                                       # 两个候选的裁剪分位数
    scale = torch.quantile(cal.abs(), q) / 127             # 只用校准数据
    raw = torch.round(val / scale)                         # 下面只用验证数据
    restored = torch.clamp(raw, -127, 127) * scale
    mse = float((val - restored).square().mean())
    sat = float((raw.abs() > 127).float().mean())          # 饱和率：超出范围的数所占比例
    print(q, scale, restored, round(mse, 4), round(sat, 4))
```

```text
1.0 tensor(0.7874) tensor([ -2.3622,  -0.7874,   0.0000,   0.7874,   2.3622, 100.0000]) 0.0588 0.0
0.8 tensor(0.0157) tensor([-2.0000, -1.0079,  0.0000,  1.0079,  2.0000,  2.0000]) 1600.6666 0.1667
```

每行依次是分位数、缩放因子、恢复值、均方误差、饱和率。

- 分位数 1.0：范围是 100。普通值 2 只能恢复成 2.3622，但 100 装得下，饱和率是 0。
- 分位数 0.8：范围只有 2。普通值几乎精确，但 100 被截成 2，饱和率 0.1667（6 个数里有 1 个），均方误差被它拉到 1600.6666。

如果饱和率上限是 0.1，第二个候选被淘汰，最后选的是分位数 1.0。两个候选各有各的误差，哪一个更好不能凭公式定，要靠验证数值上的这两个指标来比。

## 容易踩的坑

- **缩放因子用验证数值算了**：范围只能由校准数值估计，验证数值只用来量误差和饱和率。两边混用，验证结果就不是独立的证据。
- **全零输入得到缩放因子 0**：校准数值全是 0 时范围也是 0。要用最小正数保护范围，让缩放因子仍然为正。
- **先比误差再看过约束**：顺序是先淘汰饱和率超限的候选，再比均方误差。反过来的话，可能选到一个均方误差最低、但饱和率超过上限的候选。
- **没有可行候选时随便返回一个**：必须明确报错，不能退回任意分位数。
- **误差相同时没有规则**：平局时优先更高的分位数。
