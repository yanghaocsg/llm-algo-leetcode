## 一句话说清

监督微调是用“提示加标准回答”的数据继续训练模型。这本 notebook 处理一件容易做错的事：只让回答部分参与学习，提示和填充部分不算。

## 为什么需要它

预训练模型读过大量文本，擅长接着往下写，但不一定按你要的方式回答问题。监督微调（supervised fine-tuning，SFT）的做法是给它看很多“提示 + 回答”的例子，让它学会这种回答方式。

训练时模型要算一个分数，叫损失：预测离标准答案越远，损失越大。这里有三种做法会让损失算错：

- 把提示也算进损失。这样模型学的是“怎么写出用户的问题”，而不是“怎么回答”。
- 预测和标签没有错开。模型在某个位置的输出，是用来预测下一个词元的，所以预测和标签要错开一位再对齐。
- 按样本数求平均。一批里长短样本都有，填充位置不能算进损失，长短样本也不能各占一半权重。

这本 notebook 用一条样本把这三种情况走一遍，再看长短样本合成一批时损失该怎么平均。

## 先认识几个词

| 词 | 人话解释 |
|:---|:---|
| 词元（token） | 模型处理文本的最小单位。文本先被切成词元，再变成编号 |
| 提示词（prompt） | 你给模型的问题或指令 |
| 回答（response） | 你希望模型给出的内容，是真正要学的部分 |
| 损失（loss） | 衡量预测和标准答案差多远的一个数，越小越好 |
| 标签（label） | 每个位置上“正确答案”的词元编号 |
| 填充（padding） | 为了把短样本补到统一长度而加上的无效位置 |
| 结束标记（EOS） | 一个特殊词元，表示回答到这里结束 |

## 核心思路

一条样本进模型之前，要准备三排等长的数字。下面是 notebook 测试里的一条样本：提示有 3 个词元，回答有 4 个词元，后面加 1 个结束标记，总长度补到 9。

```text
位置        0     1     2     3     4     5     6     7     8
角色       提示  提示  提示  回答  回答  回答  回答  结束  填充
input_ids   10    20    30    40    50    60    70     2     0
labels    -100  -100  -100    40    50    60    70     2  -100
```

- `input_ids` 是模型实际读到的词元编号。
- `labels` 是每个位置的标准答案。`-100` 是约定的数字，表示“这个位置不算损失”。
- 还有一排 `attention_mask`（表里省略）：真实位置是 1，填充位置是 0。

算损失之前，预测和标签要错开一位：

```text
位置 2 的预测  对  位置 3 的标签 40
位置 3 的预测  对  位置 4 的标签 50
位置 6 的预测  对  位置 7 的标签 2
```

最后求平均损失：先把所有有效位置的损失加起来，再除以有效词元数，这里是 5。除以样本数是不对的，看一个小例子：

```python
short = [1.0]            # 短样本：1 个有效词元，损失 1.0
long = [0.2, 0.2, 0.2]   # 长样本：3 个有效词元，每个损失 0.2

by_token = (sum(short) + sum(long)) / (len(short) + len(long))    # 每个词元等权
by_sample = (sum(short) / len(short) + sum(long) / len(long)) / 2  # 每条样本等权
print(by_token, by_sample)
```

```text
0.4 0.6
```

按词元等权是 0.4，按样本等权是 0.6。两种算法结果不同，notebook 采用前者。

## 容易踩的坑

- **提示位置算进了损失**：提示的标签必须是 `-100`，只有回答和结束标记保留真实词元编号。
- **三个序列长度不一样**：`input_ids`、`attention_mask`、`labels` 必须等长，填充要同时加到三个序列上。
- **预测和标签没有错开**：位置 `t` 的预测要和位置 `t + 1` 的标签配对。
- **按样本数平均损失**：先求损失总和，再除以有效词元总数。直接把各微批次的平均损失再平均，短回答和长回答的权重就错了。
- **截断后一个回答词元都不剩**：提示太长，把回答挤出长度上限时，样本应该报错，不能悄悄拿去训练。
