## 一句话说清

蒸馏是让大模型教小模型。这本 notebook 处理一种做法：让小模型自己写回答，再由大模型逐个位置给出反馈，并且只在回答部分计算训练信号。

## 为什么需要它

蒸馏的常见做法是离线的：在固定数据或教师预先写好的回答上训练学生。问题是，学生部署时却要处理自己更容易产生的前缀（prefix，已经写出来的开头部分）和错误。比如学生自己写回答时，前几句一旦偏离了固定数据的写法，后面就是在自己造成的前缀上接着写。要改成“在自己的回答上学习”，容易在三个地方出错：

- 轨迹来源没记清：哪些来自固定数据、哪些是学生生成的没标出来，最后说不清收益来自数据覆盖还是在策略反馈。
- 两个比例混在一起：一个比例决定多少回答由学生生成，另一个决定怎样比较两个分布，不能互相替代。
- 无关位置算进了损失：提示、填充和不想让学生模仿的工具返回也参与平均，会改变损失分母，掩盖回答的学习信号。

这本 notebook 分三步：按比例标记一批轨迹里哪些由学生生成；把同一段前缀送给冻结（frozen，参数不再更新）的教师和学生，用广义 JSD 比较两者“下一个词元”的分布；再用完成区掩码只在回答位置上求平均，梯度只更新学生。

## 先认识几个词

| 词 | 人话解释 |
|:---|:---|
| 教师 / 学生（teacher / student） | 教师是提供反馈的大模型，参数冻结、不参与训练；学生是正在训练的小模型 |
| 轨迹（trajectory） | 一条完整的“提示 + 回答”序列，也就是一条样本 |
| 在策略 / 离线（on-policy / offline） | 在策略指回答由当前学生自己生成；离线指回答来自固定数据或教师预先生成的数据 |
| `logits` | 模型最后一层输出的一排数，还没变成概率；经过 softmax 之后才是分布 |
| KL 散度（KL divergence） | 衡量两个概率分布差多远的一个数，两个分布相同时是 0 |
| 完成区掩码（completion mask） | 一排 0 和 1，标出哪些位置属于回答、要参与蒸馏损失 |
| 停止梯度（`detach`） | 计算时把教师的输出 `detach` 掉，反向传播时梯度不会流向教师 |

## 核心思路

整条流程回答三个问题：谁生成轨迹，怎样比较两个分布，哪些位置进入损失。第一步，决定一批轨迹里有多少由学生自己生成：轨迹分布是 `(1 - λ) * μ_off(y | x) + λ * π_S(y | x)`，`x` 是输入，`y` 是回答，`μ_off` 是固定轨迹的分布，`π_S` 是当前学生的策略（policy，生成回答的方式）。`λ` 是在策略比例：等于 0 全部用固定轨迹，等于 1 全部由学生生成。“在策略”只说明轨迹从哪里来，监督信号仍由冻结的教师提供。

第二步，把同一段前缀分别送给教师和学生，各得到一个“下一个词元”的概率分布 `p_T` 和 `p_S`，再比较两者差多少。第三步，只在回答位置上求平均。两步的式子是：

```text
m_β = β * p_T + (1 - β) * p_S                         混合分布
GJS = β * KL(p_T || m_β) + (1 - β) * KL(p_S || m_β)   广义 JSD
L_distill = Σ_{b,t} M_{b,t} * GJS(p^T_{b,t}, p^S_{b,t}) / Σ_{b,t} M_{b,t}
```

`β` 在 0 和 1 之间时，先按 `β` 把两个分布混成 `m_β`，再看教师、学生各自离 `m_β` 有多远（用 KL 散度衡量），最后加权相加。两个端点单独定义：`β = 0` 时结果是 `KL(p_T || p_S)`，叫前向 KL；`β = 1` 时是 `KL(p_S || p_T)`，叫反向 KL。所以 `λ` 决定“在哪些前缀上训练”，`β` 决定“怎样比较两个分布”，不能互相替代。

`L_distill` 里，`b` 是样本编号，`t` 是词元位置，`M_{b,t}` 是掩码，1 表示参与。分子是参与位置上的差异之和，分母是参与位置的个数，叫有效蒸馏词元数；分母是 0 说明没有可学习的位置，要报错。教师保持冻结，梯度只流向学生。

用只有 3 个词元的词表试一下：

```python
import torch

pT = torch.tensor([0.7, 0.2, 0.1])      # 教师在某个位置上的下一词元分布
pS = torch.tensor([0.4, 0.4, 0.2])      # 学生在同一位置上的分布


def kl(p, q):                           # KL 散度：p 相对 q 差多远
    return (p * (p / q).log()).sum()


def gjs(pT, pS, beta):
    if beta == 0.0:
        return kl(pT, pS)               # 端点单独定义：前向 KL
    if beta == 1.0:
        return kl(pS, pT)               # 端点单独定义：反向 KL
    m = beta * pT + (1 - beta) * pS     # 混合分布
    return beta * kl(pT, m) + (1 - beta) * kl(pS, m)


print(gjs(pT, pS, 0.5), gjs(pT, pT, 0.5))     # 学生和教师不同；学生和教师相同
print(gjs(pT, pS, 0.0), kl(pT, pS))           # beta = 0：前向 KL
print(gjs(pT, pS, 1.0), kl(pS, pT))           # beta = 1：反向 KL
print("硬代入通式:", 0.0 * kl(pT, pS) + 1.0 * kl(pS, pS))

per_token = torch.tensor([5.0, 1.0, 3.0])     # 三个位置各自的差异，数字是示意
mask = torch.tensor([0.0, 1.0, 1.0])          # 位置 0 是提示，后两个是回答
print((per_token * mask).sum() / mask.sum(), per_token.mean())   # 只在掩码为 1 的位置求平均；全部位置求平均
```

```text
tensor(0.0462) tensor(0.)
tensor(0.1838) tensor(0.1838)
tensor(0.1920) tensor(0.1920)
硬代入通式: tensor(0.)
tensor(2.) tensor(3.)
```

- 第 1 行：学生和教师不同时差异是 0.0462，相同时是 0。
- 第 2、3 行：两个端点的结果分别等于前向 KL 和反向 KL，所以每行前后两个数相同。
- 第 4 行是个提醒：把 `β = 0` 直接代进通式，混合分布就变成 `p_S`，结果恒为 0，所以端点必须单独定义。
- 第 5 行是掩码的作用：三个位置的差异是 5.0、1.0、3.0，位置 0 是提示。只在后两个位置求平均是 2.0，把提示算进去就变成 3.0。

## 容易踩的坑

- **λ 和 β 混用**：`λ` 决定一批轨迹里有多少由学生生成，`beta` 决定怎样比较两个分布。教师温度只管教师分布的平滑程度，和掩码、分母无关。
- **在策略样本的数量或位置不对**：比例先换算成样本数（8 条里取 50% 就是 4 条），再用固定随机种子随机挑位置。同一个种子要得到同一份分配，不要让学生轨迹固定落在批次前几条。
- **提示、填充或工具返回进了掩码**：完成区掩码只保留回答位置。本题用右侧填充（没有左填充），提示长度按位置计数，排除区要再减掉。
- **分母用错，或者空掩码返回 0**：分母是掩码为 1 的位置数，不是批大小或序列长度。分母为 0 时直接报错，不能产生一个假的 0 损失。
- **端点硬代入通式，或者梯度流向了教师**：`beta` 等于 0 和 1 时要单独返回前向 KL 和反向 KL。教师的 `logits` 要先停止梯度再转成分布，梯度只进入学生。
